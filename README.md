# CitaBot Valencia — Home Assistant OS

## Важливо про функціональність
Це безпечна перша версія Telegram-помічника: приватний доступ, команди `/start`, `/cita`, `/check`, посилання на офіційний ICP+ та інструкція для процедури Toma de huellas.

Вона **не моніторить автоматично наявність слотів**. Державний ICP+ працює через JavaScript і може застосовувати захисні перевірки; у відкритих офіційних матеріалах не знайдено документованого публічного API доступності слотів. Не можна вважати результат перевірки доступністю, якщо його не підтверджує сам портал. CAPTCHA та інші захисти проходьте вручну.

## Встановлення
1. У Home Assistant відкрийте **Settings → Apps → App store**.
2. У меню App store оберіть **Repositories** або **⋮ → Repositories**, якщо цей пункт доступний у вашій версії.
3. Для локального встановлення скопіюйте папку `citabot` до каталогу локальних apps/add-ons, який використовує ваша інсталяція HA OS (зазвичай `/addons/local_apps/citabot` у новому форматі).
4. Оновіть список локальних apps та встановіть **CitaBot Valencia**.
5. Створіть Telegram-бота через `@BotFather` командою `/newbot` та скопіюйте токен.
6. Дізнайтеся свій Telegram numeric chat ID через надійний спосіб/бот для показу ID. Не надсилайте токен або ID в публічні чати.
7. У налаштуваннях CitaBot задайте `telegram_bot_token` і `allowed_chat_id`.
8. Запустіть app і відкрийте свого бота в Telegram: натисніть Start або надішліть `/start`.

## Безпека
- Токен вводиться лише в налаштуваннях app у Home Assistant.
- Бот відповідає лише одному `allowed_chat_id`.
- Не вставляйте токен у YAML автоматизацій, скриншоти чи публічні повідомлення.
- Якщо токен розкрито, відкличте його в BotFather і створіть новий.
